# Поруч

Мобільний застосунок для дорослих пар (18+): ігри, плани побачень, сценарії, масаж, сексологія, щоденні практики та «натяки» партнеру. Android + iOS, один код на Expo (React Native). Працює повністю локально — без акаунтів і сервера.

## Запуск

```bash
npm install
npx expo start          # відскануйте QR у застосунку Expo Go
npx expo start --web    # перегляд у браузері
npm run typecheck
```

Збірка для магазинів: `npx eas-cli@latest build -p android` / `-p ios`.

## Структура

- `src/app/` — екрани (Expo Router): онбординг, вкладки Меню / Натяк / Профіль, розділи, ігри.
- `src/data/` — увесь контент. Нові плани, сценарії чи картки додаються сюди, код міняти не треба.
- `src/i18n.ts` — тексти інтерфейсу (українська, російська, англійська).
- `src/theme.ts` — назва застосунку та кольори.
- `src/store.tsx` — стан і збереження на телефоні (AsyncStorage).

## Що працює як заглушка

- **Підписка** — платежі не підключені; кнопка «Оформити» вмикає Premium локально.
- **Режим пари** — код генерується й приймається, але телефони між собою не зв'язані (немає сервера).
- **Натяки** — надсилаються через системне меню «Поділитися» у будь-який месенджер.
- **Контент** — українською; інтерфейс перекладено трьома мовами.
