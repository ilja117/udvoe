# Поруч

Мобільний застосунок для дорослих пар (18+): ігри, плани побачень, сценарії, масаж, сексологія, щоденні практики та «натяки» партнеру. Android + iOS, один код на Expo (React Native). Працює повністю локально — без акаунтів і сервера.

## Запуск на телефоні

Потрібен комп'ютер із Node.js 20+.

**Швидко, через Expo Go (Android та iOS):**

1. Встановіть на телефон застосунок **Expo Go** з Google Play або App Store.
2. На комп'ютері: `npm install`, потім `npx expo start`.
3. Телефон і комп'ютер мають бути в одній Wi-Fi мережі. На Android відскануйте QR-код із термінала в Expo Go, на iPhone — звичайною камерою.
4. Якщо не з'єднується — запустіть `npx expo start --tunnel`.

**Окремий APK для Android (працює без комп'ютера):**

1. Зареєструйтеся безкоштовно на expo.dev.
2. `npx eas-cli@latest login`
3. `npx eas-cli@latest build -p android --profile preview`
4. Після збірки відкрийте посилання на телефоні, завантажте й встановіть APK.

**iPhone без Expo Go** потребує платного Apple Developer акаунта: `npx eas-cli@latest build -p ios`.

Перегляд у браузері: `npx expo start --web`. Перевірка типів: `npm run typecheck`.

## Структура

- `src/app/` — екрани (Expo Router): онбординг, вкладки Меню / Натяк / Профіль, розділи, ігри.
- `src/data/` — увесь контент; у `src/data/extra/` — додаткові матеріали у форматі `Назва | Опис | крок | крок`.
- `src/i18n.ts` — тексти інтерфейсу (українська, англійська).
- `src/theme.ts` — назва застосунку та кольори.
- `src/store.tsx` — стан і збереження на телефоні (AsyncStorage).

## Обмеження

- **Режим пари** — код генерується й приймається, але телефони між собою не зв'язані (немає сервера).
- **Натяки** — надсилаються через системне меню «Поділитися» у будь-який месенджер.
- **Контент** — українською; інтерфейс є українською та англійською.
